# Laboratorio 6 - M-QAM

Este repositorio contiene los archivos correspondientes al laboratorio de modulación M-QAM.  
Incluye:
- Diagramas de bloques de GNU Radio (.grc)
- Capturas de resultados y constelaciones
- Código de simulación y análisis
- Informe en formato IEEE (PDF)

## Ejecución
1. Abrir el archivo lab6_mqam.grc en GNU Radio.
2. Ejecutar para observar las constelaciones de BPSK, QPSK, 8PSK y 16-QAM.
3. Comparar las versiones base y pasa banda.
